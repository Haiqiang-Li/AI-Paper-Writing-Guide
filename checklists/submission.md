# 提交前检查表

此表是通用自查工具，逐项对照本次投稿的官方要求，不以往年规则代替核实。

## 论证与结果

- [ ] 任务定义、假设与主要贡献清楚。
- [ ] 每一项贡献都能找到相应证据。
- [ ] 摘要、正文、表格中的数字一致且可追溯。
- [ ] 基线、数据划分和调参预算的比较条件明确。
- [ ] 误差、重复次数、统计口径和成本范围有说明。
- [ ] 局限与失败情形没有被有意隐藏。

## 阅读与排版

- [ ] 术语、缩写、符号、单位前后一致。
- [ ] 图表在正文被引用，图题能够解释关键条件。
- [ ] 最终尺寸下图表文字可读，公式不越界。
- [ ] 无未解析的引用、残留 TODO 或错误占位符。
- [ ] 参考文献信息与出版记录一致，重要相关工作未遗漏。
- [ ] 论文结构、页数、匿名与补充材料满足本次官方要求。

## 复现与文件

- [ ] 必要的数据处理、依赖、运行配置和评价协议已记录。
- [ ] 代码、附件和外链中的身份信息符合匿名规则。
- [ ] PDF 元信息、致谢、文件名和附录已检查。
- [ ] 所有作者已核对稿件、作者信息和提交范围。
- [ ] 数据、图片和第三方内容具有适当使用依据并已注明来源。
- [ ] 下载并打开提交系统中的最终文件，确认版本正确。
- [ ] 保存提交回执、稿件版本与截止时间记录。
