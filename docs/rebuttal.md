# 审稿回复：让问题、证据与修改一一对应

先读当年的回复规则，确认字数、格式、匿名要求，以及是否允许新增实验、链接或材料。这里提供通用写法，不假定所有会议采用相同流程。

## 先理解问题，再开始答复

将意见分为：事实误解、表达不清、证据不足、研究范围分歧。记录每一条的原始位置，并标记它是否影响论文的核心结论。

优先处理影响有效性的问题，随后回答贡献边界与实验公平性，最后处理表达和排版。不要把所有篇幅花在容易回答的小问题上。

## 一条回复的四个组成部分

1. **问题**：准确概括审稿人的疑问，不挑选容易反驳的片段。
2. **回答**：直接说明同意、不同意或需要澄清的部分。
3. **依据**：指向现有图表、推导、设置，或规则允许的新证据。
4. **修改**：说明已修改和计划修改的位置，区分两者。

如果对方指出真实错误，承认并说明影响与修正；必要时简短致歉。没有必要套用“绝不道歉”的绝对规则，也不要用礼貌表达代替实质回答。

## 写作边界

- 不把尚未完成的实验写成已验证。
- 不声称审稿人“没有认真读”，而是明确补上容易遗漏的信息。
- 不把相关性表述升级为因果解释。
- 如果结论只在较窄范围内成立，应主动收缩措辞。
- 使用当前投稿平台预览检查公式和链接，不假定它与本地 LaTeX 完全一致。

使用 [回复模板](../templates/rebuttal.md) 记录具体内容。投递后保留最终版本与证据记录，便于后续修订。
